# Team Fortress 2 Takeover

**Terraria** × Team Fortress 2 · visual · idea by the team

Bring Team Fortress 2 into the game in the most visible and funny way. The change shows in the first 30 seconds of play.

> I turned the forest into a Team Fortress battlefield: RED Scouts, Soldiers and Pyros vs BLU Heavies, all ragdolling into confetti when rocketed.

## Install

Copy Sigf.tmod into Documents/My Games/Terraria/tModLoader/Mods and enable the mod in tModLoader's Mods menu. Start a world in a forest: mercenaries spawn there, and Red Soldiers sometimes drop the Rocket Launcher.
